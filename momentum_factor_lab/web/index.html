읽는 방법

대시보드 설명

  • Python 선택 팩터는 입력 폼의 평가기간에서 네 가지 비중 정책을 포함한 전체 조합 중 합성 점수와 가드레일을 통과해 선택된 결과입니다.
  • 모멘텀 신호는 해당 팩터가 계산한 종목별 점수이며, 높을수록 상위 후보입니다.
  • 기간 수익률 1위는 성과 탐색 기간의 과거 누적 수익률만 가장 높은 비교선이며 공식 선택을 뜻하지 않습니다.
  • 비교할 팩터는 성과와 보유 이력을 살펴보기 위한 선택입니다. 공식 선택 팩터·정책·포트폴리오는 바뀌지 않습니다.
  • 선택 포트폴리오는 Python이 Top-N, 비중 정책, 종목당 상한을 적용한 결과이며 남는 금액은 현금으로 표시합니다.
  • 입력 폼을 제출하면 정확한 정적 preset을 열거나 로컬 Python API에서 전체 분석을 새로 실행합니다.
  • 데이터 품질, 유동성, 생존편향, 무료 데이터 한계는 기존 리포트와 동일하게 적용됩니다.

수동 업데이트

검토 후 그 시점의 최신 데이터로 수동 실행

자동 예약 실행은 현재 중지되어 있습니다. 버튼을 누르면 GitHub Actions 수동 실행 화면으로 이동합니다. workflow_dispatch 실행이며, 저장소 쓰기 권한이 있는 GitHub 계정으로 Run workflow를 누릅니다.

공개 페이지에는 GitHub 토큰을 저장하지 않습니다. 실행 후 Actions 상태와 대시보드 기준일을 확인하세요.

GitHub Actions에서 최신 데이터 업데이트 실행 gh workflow run daily-dashboard.yml --repo SonChangGi/momentum-factor-lab --ref main 실행 후 변경사항이 있으면 새 JSON이 커밋되고 Pages가 갱신됩니다. Actions 상태와 대시보드 기준일을 확인하세요.
